SECTION 01

A register is just 32 switches

A hardware register is a row of bits living at a fixed memory address. Each bit is a tiny switch wired to something real — a pin, a mode, an enable. To control the chip, you flip the right switches without disturbing the others.

Three operations do almost everything. Each uses a mask — a number with 1s in the positions you care about — and a bitwise operator:

  • Set a bit: reg |= mask — OR forces the bit to 1.
  • Clear a bit: reg &= ~mask — AND with an inverted mask forces it to 0.
  • Toggle a bit: reg ^= mask — XOR flips it.

For a 32-bit mask in C, include <stdint.h> and use uint32_t mask = UINT32_C(1) << n;, with 0 ≤ n < 32. A signed 1 << 31 is not a portable way to set bit 31.

These operations model an ordinary read/write register. Masked read-modify-write preserves unrelated bits only when register semantics and concurrency permit it. Write-one-to-clear flags need a direct mask write; write-only, read-clear, and mixed-access registers need their documented access sequence.
